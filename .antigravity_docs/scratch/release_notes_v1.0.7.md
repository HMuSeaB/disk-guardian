## 🚀 DiskGuardian v1.0.7 发布说明

### 1. 任务栏与窗口图标双重保活修复
- **解决任务栏默认白色方块问题**：构建输出显式包含 `disk-guardian.ico`；
- **底层应用标识注册**：通过 Win32 `SetCurrentProcessExplicitAppUserModelID` 注册专属进程 AppID；
- **双重图标注入**：同时向窗口句柄注入 `AppWindow.SetIcon` 与 `WM_SETICON`（大图标 32x32 与小图标 16x16），彻底消除 Windows 任务栏、Alt+Tab 预览与标题栏的图标缺失问题。

### 2. 清理项选择体验革新
- **【仅选此项】一键单选**：每个规则卡片右侧新增【仅选此项】按钮，点击自动清空其它勾选并单独选中当前项，彻底告别“单选某项必须一个个取消”的烦恼；
- **全能控制矩阵**：支持【仅选L1(推荐)】、【全选当前】、【反选】、【清空选择】。

### 3. 清理视图分类与搜索重塑（彻底告别滑动条）
- **分类标签平铺化**：彻底移除丑陋的横向 `ScrollViewer` 滑动条，精简标签文案（`🌟 全部`、`💻 开发`、`🎮 游戏`、`💬 软件`、`🪟 系统`、`🐳 容器`），自然平铺，绝不遮挡；
- **即时搜索框**：支持实时过滤规则名称、说明与路径关键字，输入即搜，秒级定位。
